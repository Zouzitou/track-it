# UI copy

Track it uses direct, user-side language: “Import video,” “Select subject,” “Add to
selection,” “Remove from selection,” “Track forward,” “Track backward,” “Track both ways,”
“Stop tracking,” “Add correction,” “Clear this range,” “Export masks,” “Export motion data,”
“Download model,” “Retry,” “Relink video,” and “Open diagnostics.”

The empty workspace says “Start with a video” followed by “Import a video, pause on a clear
frame, then select the subject you want to track.” Errors state cause and recovery and never
use apology filler, hype, or a vague “Something went wrong.”
